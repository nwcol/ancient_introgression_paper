Some exploratory models.

ooa_model/ A 4-deme OOA model.

mig_ooa_model/ Same as the above, but with symmetric migration between the
    Loschbour and Yoruba demes.

trio_africans_model_0/ Stuttgart, Yoruba and Khomani San demes. K.San as the 
    "outgroup:. To determine whether these lineages can be well-modeled as a 
    tree.
african_trio_models/ A larger version of the above, with three simple models:
        model 0: K.San as "outgroup"
        model 1: Stuttgart as outgroup 
        model 2: Yoruba as outgroup.
    This is motivated by the collision of divergence times in the above. It's 
    also meant to be suggestive about the OOA event for the Stuttgart lineage

topologies/ fitted on the cluster. 5 demes (Yoruba, Vindija, 3 OOA) These 
    models are tested:
        model 1: the null model. Stuttgart diverges from Loschbour.
        model 2: Stuttgart diverges from OOA before N->H admixture
        model 3: Basal branch diverges from OOA and forms Stuttgart by admixture
            with Loschbour 
        model 4: Basal branch diverges before primary OOA event.
