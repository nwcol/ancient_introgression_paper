Bootstrap LRT on superarchaic admixture models. Run at the same time as 
mass fit 2.

Basically the goal is to be able to evaluate support for superarchaic admixture 
in models with/ without the H->N pulse. (Neanderthal/Denisova migration is 
included in all models).

Model layout.
    S pulses            none    S->ND   S->D    both
H->N pulse?     Yes     0       1       2       3
                No      4       5       6       7

For now I use only the Bherer dataset.
