


Abbreviated names for model sets:
model0: null model, lacking ghost->Denisova introgression
model1: first alternate model, with ghost->Denisova introgression but lacking
    modern human->Neanderthal introgression 
model2: second alternate model, with both introgression pulses.

The second model requires two parameterizations to cope with the fact that the 
Neanderthal pulse time is a free parameter. Case 0 denotes the case where 
the ghost introgression happens more recently.
